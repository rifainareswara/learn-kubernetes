## Cara Mengerjakan Project

1. Baca README project untuk memahami arsitektur
2. Coba buat manifest YAML sendiri dulu
3. Jika stuck, lihat solusi di file yang disediakan
4. Verifikasi sesuai checklist yang ada
5. Lakukan cleanup setelah selesai
