# Alibaba Cloud Container Service for Kubernetes (ACK)

ACK adalah managed Kubernetes service dari Alibaba Cloud. Pilihan populer untuk deployment di Asia-Pasifik, terutama Indonesia dan kawasan regional.

---

## Mengapa ACK?

- Data center di Indonesia (Jakarta region: ap-southeast-5)
- Biaya lebih terjangkau dibanding AWS/GCP untuk beban kerja di Asia
- Integrasi dengan ekosistem Alibaba (OSS, RDS, SLB)
- Dukungan Mandarin dan Indonesia
