# Amazon Elastic Kubernetes Service (EKS)

EKS adalah managed Kubernetes service dari Amazon Web Services (AWS). Pilihan utama jika tim sudah ada di ekosistem AWS.

---

## Mengapa EKS?

- Integrasi dengan layanan AWS (S3, RDS, ALB, CloudWatch)
- IAM untuk autentikasi dan otorisasi
- Populer di enterprise yang sudah pakai AWS
- EKS Fargate: serverless Kubernetes (tanpa kelola Node)
