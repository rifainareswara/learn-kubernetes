# Google Kubernetes Engine (GKE)

GKE adalah managed Kubernetes service dari Google Cloud. Wajar saja, karena Kubernetes sendiri diciptakan oleh Google!

---

## Mengapa GKE?

- Google adalah "pencipta" Kubernetes — GKE selalu update lebih cepat
- Integrasi sempurna dengan Google Cloud (Storage, Pub/Sub, BigQuery)
- Autopilot mode: tidak perlu kelola Node sama sekali!
- Free tier: cluster kecil gratis (satu zonal cluster)
